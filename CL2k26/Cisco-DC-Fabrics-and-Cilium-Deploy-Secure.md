# Cisco DC Fabrics and Cilium: Deploy, Secure, and Observe Cloud-Native Applications

Unlock the full potential of your cloud-native applications by integrating Cilium with Cisco Application Centric Infrastructure (ACI) and NX-OS VXLAN EVPN. In this session, you’ll discover how to seamlessly deploy modern applications while leveraging advanced networking and security capabilities across multiple Cisco platforms. The lab will guide you through step-by-step configuration of Cilium with ACI/NX-OS, demonstrating how to apply Kubernetes-native network policies for workload security and utilize Cilium’s robust observability features for enhanced visibility and troubleshooting. You’ll also learn how to use ACI/NX-OS security policies to secure north-south (N/S) communication. To provide comprehensive end-to-end visibility, you’ll see how Cisco Nexus Dashboard Insights (NDI) can be configured and used across both ACI and NX-OS VXLAN EVPN environments. This session provides practical, hands-on insights and best practices to build, secure, and monitor your applications with confidence across both ACI and NX-OS VXLAN EVPN.
