# Network Testing with pyATS - Level III: Advanced Network Testing Using Sources of Truth [DEVWKS-3540]

As you progress in your pyATS journey, you will begin to realize the limitations of managing large amounts of network topology information in YAML files. Your network continues to evolve, but the pyATS testbed never seems to stay in sync.

Network Sources of Truth (NSoT) are the answer to your struggle.

In this session, attendees will obtain the URL and API token for a NetBox instance from HashiCorp Vault.

After a connection to NetBox is established, you will filter the available devices to generate a pyATS testbed from the NetBox data, and then perform compliance testing to ensure your devices are operating as defined in the NSoT.

It's time to move away from YAML and take a step into modern network automation using pyATS and Sources of Truth.
